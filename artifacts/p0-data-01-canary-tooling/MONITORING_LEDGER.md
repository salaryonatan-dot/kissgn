# MONITORING LEDGER (`monitor --cycle YYYY-MM-DD [--receipts file]`)

One immutable record per business day in `ledger/cycle-<date>.json` (+ `ledger.jsonl`). Re-running with an identical body appends nothing; a different body appends `cycle-<date>-cN.json` with `correction: N` and `supersedes: <prior bodyDigest>` — the earlier file is never rewritten. The window arithmetic uses the latest record per cycle.

Record: `recordVersion, cycleId, anchorDate, slots` (analytics 23:00Z, proactive 03:00Z+1, alerts 04:00Z+1, snapshot 04:05Z+1, deadline 06:00Z+1, rendered in the manifest timezone — DST-neutral), `identity, versions` (repo sha, policy phase/revision/operation, schemaVersion, generation, previous generation, storage mode), `source` (node digest, previous digest, frozen `_v` sha and previous, row count, sorted-ids digest, exceptions/context digests, latest date), `mutations` = row-count equation `rowsStart + creates − deletes = rowsEnd` (from receipts; failure ⇒ `unexplained_row_delta` STOP), `ui`, `counters` (receipts + `malformedV2` from the readers + `storageModeMismatch`), `derived` (`analyticsDaily`, `insightsDaily`, `proactiveDigest`, `proactiveInsights` read at the exact derived paths; `snapshotEmail`/`alerts` from receipts, recipient hashed) each `PRESENT | MISSING | UNKNOWN`, `reconciliation` (readers over the live node for the cycle date vs the stored analytics doc: revenue/labor/purchases/ratios `Object.is` diff ⇒ `financial_drift` STOP; owner totals from receipts), `incidents`, `findings`, `classification`, `cycle: COMPLETE | INCOMPLETE`, `incompleteReasons`, `bodyDigest`.

Rules: any `UNKNOWN`/`MISSING` derived output ⇒ INCOMPLETE (never PASS); STOP-level findings (generation change, frozen `_v` change, policy change, malformed V2, financial drift, old-client write, unexplained row delta) ⇒ INCOMPLETE + exit 12 + `RECOVERY_HOLD_RECOMMENDED` (no transition). Window (`status`): `elapsedHours ≥ 168` since `liveWriteCleanupAt` **and** `cleanStreak ≥ 7` consecutive COMPLETE cycles with level OK/EXPECTED/WARNING, and the last cycle not a STOP ⇒ `windowMet`. Advancement to a second business is blocked while an un-acknowledged STOP exists.
