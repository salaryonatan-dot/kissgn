# DRAIN STATE BINDING (R1 — Finding 3)

**Drain artifact.** A `drain-check` report now carries `bound` = `drainBinding({samples, control, manifest, derivedDate})`:
`start` / `mid` / `end` digests (`digestV1`) of the entries node, the exceptions node, the context (config/fixed/suppliers), the control record and the derived docs of the sampled day; `accepted` = the end digests when all three samples agree (else `null`); `policyRevision`, `phase`, `operation {id, kind, owner}` of the record the drain was observed under; `target {tenantId, bizId, operationId}`; `derivedDate`.

**Capture binding.** `capture` reads the current state, computes `currentStateDigests` and evaluates `checkDrainBinding(latestDrain, current, control, manifest)`: `BOUND` only if every sampled digest (entries, exceptions, context, control — and derived when the same day), the policy revision, the phase, the operation ownership and the target are identical; `STALE` on any difference ⇒ typed refusal `drain_evidence_stale` (exit 11) **before anything is written**; `UNPROVEN` / `MISSING` keep the held preflight at OPERATOR_ACTION_REQUIRED (`final_preflight_conditions`). A second read inside `capture` must still equal the accepted entries digest. The binding (`drain.json`, including the evaluated `binding`) is written into the evidence bundle; `final_held_conditions` PASS requires `BOUND`.

**Migration binding.** Before the CAS marker, `migrate` requires: (a) the bundle's `drain.json` with verdict `DRAIN_EVIDENCE_COMPLETE` and `accepted` digests (`drain_evidence_required`); (b) `accepted.entries === sourceManifest.sourceDigest` (`drain_evidence_mismatch`); (c) `checkDrainBinding` against the CURRENT state = `BOUND` (`drain_evidence_stale`); then (d) the warm read digest === evidence digest (`source_drift_before_transaction`) and (e) the digest check on every transaction callback. The dry-run plan reports `drainBoundDigest` and `drainPolicyRevision`. Timestamps play no part in any of these decisions.

**Policy binding.** A later revision, a phase change, or a change of operation ownership makes the drain evidence STALE (mismatch keys `policyRevision`, `phase`, `operation`, and `control` since the record digest changes too).
